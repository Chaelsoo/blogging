Personal blog built with Hugo and the hugo-blog-awesome theme.
Live at: https://chaelsoo.me

## Stack
- Hugo v0.161.1 extended
- hugo-blog-awesome theme (via Hugo modules)
- Deployed on GitHub Pages via GitHub Actions
- Custom domain: chaelsoo.me

## Writing
Blog posts live in `content/blogs/` and writeups in `content/writeups/` as `.md` files.

## Local development
```bash
hugo server --disableFastRender
```
